# Upstream relational datasets

These datasets import tables supplied by the original publisher into SQLite. Use them to study existing schemas and documented business fields. Open a dataset for its ERD, dictionary, conversion decisions and source attribution.

| Dataset | Original data | Getting the SQLite input | Evaluation resources |
|---|---|---|---|
| [AdventureWorks](adventureworks/) | Microsoft’s sample SQL Server OLTP exports | Checked-in SQLite | Table previews and EEG reviewer |
| [MIMIC-IV Demo](mimic/) | Deidentified hospital and ICU records from PhysioNet | Decompress the checked-in archive | Admission-timeline draft and EEG reviewer |
| [Olist](olist/) | Anonymized marketplace tables distributed as CSV | Decompress the checked-in archive | Source provenance, relational schema and row counts |
