# AdventureWorks data dictionary

Descriptions below are extracted verbatim from Microsoft `MS_Description` extended properties. Missing descriptions remain explicitly absent; no event or Entity Type gold labels are added.

## dbo.DatabaseLog

Audit table tracking all DDL changes made to the AdventureWorks database. Data is captured by the database trigger ddlDatabaseTriggerLog.

| Column | SQL Server type | SQLite type | Key | Description |
|---|---|---|---|---|
| DatabaseLogID | int | INTEGER | PK | Primary key for DatabaseLog records. |
| PostTime | datetime | TEXT |  | The date and time the DDL change occurred. |
| DatabaseUser | sysname | TEXT |  | The user who implemented the DDL change. |
| Event | sysname | TEXT |  | The type of DDL statement that was executed. |
| Schema | sysname | TEXT |  | The schema to which the changed object belongs. |
| Object | sysname | TEXT |  | The object that was changed by the DDL statment. |
| TSQL | nvarchar | TEXT |  | The exact Transact-SQL statement that was executed. |
| XmlEvent | xml | TEXT |  | The raw XML data generated by database trigger. |

## dbo.ErrorLog

Audit table tracking errors in the the AdventureWorks database that are caught by the CATCH block of a TRY...CATCH construct. Data is inserted by stored procedure dbo.uspLogError when it is executed from inside the CATCH block of a TRY...CATCH construct.

| Column | SQL Server type | SQLite type | Key | Description |
|---|---|---|---|---|
| ErrorLogID | int | INTEGER | PK | Primary key for ErrorLog records. |
| ErrorTime | datetime | TEXT |  | The date and time at which the error occurred. |
| UserName | sysname | TEXT |  | The user who executed the batch in which the error occurred. |
| ErrorNumber | int | INTEGER |  | The error number of the error that occurred. |
| ErrorSeverity | int | INTEGER |  | The severity of the error that occurred. |
| ErrorState | int | INTEGER |  | The state number of the error that occurred. |
| ErrorProcedure | nvarchar | TEXT |  | The name of the stored procedure or trigger where the error occurred. |
| ErrorLine | int | INTEGER |  | The line number at which the error occurred. |
| ErrorMessage | nvarchar | TEXT |  | The message text of the error that occurred. |
