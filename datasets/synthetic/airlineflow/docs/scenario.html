승객 속성과 공개 모델 비교

passengers에 생년월일(date_of_birth), 국적(nationality_code), 성별(gender_code)을 추가했습니다. 모든 값은 가상입니다. 생년월일은 승객 속성이며 업무 사건의 시각으로 사용하지 않습니다. 국적은 예시에서 기록한 단일 국적으로 거주국이나 문서 발급국과 구분합니다. 성별은 MALE/FEMALE/UNKNOWN의 로컬 코드로 저장합니다.

공개 자료확인한 대응과 적용 범위
Postgres Pro Airlines 2017 계열교육용 데모 DB. bookings–tickets–ticket_flights 관계와 대응합니다. 이 버전은 승객 정보를 tickets에 두므로 별도 passengers 테이블은 우리 예시의 정규화 설계입니다. 우리 passenger_id는 내부 가명 ID입니다.
Amadeus 공식 예약 예제여행자에 dateOfBirth와 gender, 여행 문서에 nationality가 있습니다. API 정보 모델의 근거이며 항공사 내부 물리 DB 구조의 증거와 구별합니다. 우리 예시는 국적을 승객 명부에 단순화했습니다.
EUROCONTROL A-CDM탑승과 준비 완료·출발 사건을 구별하는 근거입니다. turnarounds.inbound_id와 outbound_id로 동일 기체의 입항·출항을 연결했습니다. 입항편의 LAND·IN, 지상조업, 출항편의 OUT·AIR를 구분하며 T 질의로 연결해 읽습니다. 본 예시는 기체 교체 없는 완료된 턴어라운드입니다.

현재 자료는 공개 DB 관계와 운영 개념을 참고한 합성 사례입니다. 보안검색 기록은 공항 연계를 가정했습니다. 운임·결제·좌석·문서 이력, 재예약·회항·반복 탑승 세션은 단순화했습니다. 승객과 가방은 편당 일부 예시 레코드입니다. 편 전체 작업 마감은 별도 조업 기록에서 읽으며 개별 가방 스캔의 최댓값으로 추정하지 않습니다.
